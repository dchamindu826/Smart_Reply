# Smart Reply — Flutter app

The Android and iOS app for managers and staff: chats, WhatsApp calls, customers, status and
breaks, push notifications. It talks to the same API as the web app.

> The repository also has a React Native version in `mobile/`. Use one of them; this Flutter
> app is the main one.

## 1. First-time setup

You need Flutter 3.27 or newer (`flutter --version`) and Android Studio (for Android) or Xcode (for iOS).

The platform folders (`android/`, `ios/`) are generated by Flutter on your machine:

```bash
cd flutter_app
flutter create . --org lk.lumiai --project-name smart_reply --platforms android,ios
flutter pub get
```

`flutter create .` keeps `lib/` and `pubspec.yaml`; it only adds the missing folders.
Delete the generated `test/widget_test.dart` (it tests Flutter's counter sample).

### Android permissions — `android/app/src/main/AndroidManifest.xml`

Inside `<manifest …>` (above `<application>`):

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.MODIFY_AUDIO_SETTINGS" />
<uses-permission android:name="android.permission.BLUETOOTH_CONNECT" />
<uses-permission android:name="android.permission.POST_NOTIFICATIONS" />
<uses-permission android:name="android.permission.WAKE_LOCK" />
```

For testing against a local API over plain `http://`, add `android:usesCleartextTraffic="true"`
to the `<application …>` tag (remove it for the store build; production uses HTTPS).

### Android SDK level — `android/app/build.gradle` (or `build.gradle.kts`)

In `defaultConfig` set `minSdk = 24`.

`flutter_local_notifications` needs core library desugaring. In the same file:

```kotlin
android {
    compileOptions {
        isCoreLibraryDesugaringEnabled = true   // Groovy: coreLibraryDesugaringEnabled true
    }
}
dependencies {
    coreLibraryDesugaring("com.android.tools:desugar_jdk_libs:2.1.4")
}
```

### iOS permissions — `ios/Runner/Info.plist`

```xml
<key>NSMicrophoneUsageDescription</key>
<string>Smart Reply uses the microphone for WhatsApp calls and voice messages.</string>
<key>NSCameraUsageDescription</key>
<string>Smart Reply uses the camera to send photos to customers.</string>
<key>NSPhotoLibraryUsageDescription</key>
<string>Smart Reply lets you send photos and videos to customers.</string>
<key>UIBackgroundModes</key>
<array>
  <string>audio</string>
  <string>voip</string>
  <string>remote-notification</string>
</array>
```

In `ios/Podfile` set `platform :ios, '13.0'`.

## 2. Run it

Start the API first (see the main README), then:

```bash
flutter run
```

On the sign-in screen tap **Server: … Change** and enter the API address:

| Where the app runs | Server address |
|---|---|
| Android emulator, API on your computer | `http://10.0.2.2:4000` (default) |
| Real phone on the same Wi-Fi | `http://<your computer's LAN IP>:4000`, e.g. `http://192.168.1.20:4000` |
| Production | `https://app.yourdomain.com` |

Demo logins (after `npm run db:seed:demo -w backend`): `manager@demo.test` / `staff1@demo.test`,
password `Demo12345!`.

You can also bake the address into a build: `flutter run --dart-define=API_URL=https://app.yourdomain.com`.

## 3. Push notifications (Firebase)

1. Create a project at console.firebase.google.com and add an **Android** app with package
   `lk.lumiai.smart_reply` and an **iOS** app with bundle id `lk.lumiai.smartReply`
   (check the exact ids Flutter generated).
2. Easiest: `dart pub global activate flutterfire_cli` then `flutterfire configure` in `flutter_app`.
   Or download `google-services.json` to `android/app/` and `GoogleService-Info.plist` to `ios/Runner/`
   and add the Google services Gradle plugin as Firebase's Android guide shows.
3. iOS: upload an APNs key in Firebase → Project settings → Cloud Messaging.
4. Server: Firebase → Project settings → Service accounts → **Generate new private key**. Put the JSON,
   on one line, in `FCM_SERVICE_ACCOUNT_JSON` (`backend/.env` locally, `infra/.env` on the server).

Without Firebase files the app still runs; it just gets no push notifications.

## 4. Build for the stores

```bash
flutter build apk --release --dart-define=API_URL=https://app.yourdomain.com          # APK to share directly
flutter build appbundle --release --dart-define=API_URL=https://app.yourdomain.com    # Play Store
flutter build ipa --release --dart-define=API_URL=https://app.yourdomain.com          # App Store (on a Mac)
```

Before the Play Store build, create an upload key and signing config as in Flutter's
"Build and release an Android app" guide.

## What is in `lib/`

| File | What it does |
|---|---|
| `main.dart` | Starts the app, Firebase, chooses sign-in or home |
| `core/api.dart` | HTTP client, tokens in secure storage, automatic refresh, uploads |
| `core/webrtc.dart` | WhatsApp calling: the phone is the audio peer (offer/answer with all ICE candidates in the SDP) |
| `core/push.dart` | Firebase push and tap-to-open chat |
| `state/app_state.dart` | Session, chats, messages, team, live events over Socket.IO |
| `screens/` | Sign in, chats, chat, customer info, templates, calls, call screen, customers, me |
| `models/models.dart` | API objects (match `packages/shared/src/types.ts`) |
